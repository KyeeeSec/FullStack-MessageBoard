# Simple Full-Stack message powered by supabase ⚡ (Python, Supabase, Flask)

# Instructions to setup:
 1) Ensure you have a supabase account and database set up and running
 2) Add the following tables
     * id (lowercase, of type number)
     * text (lowercase aswell, of type text)
 3) Next, create a file called .env, and define SUPABASE_KEY and SUPABASE_URL with your supabase private key and URL to your project.
  
 4) Visit 127.0.0.1 at port 5001 and enjoy the message board :)
